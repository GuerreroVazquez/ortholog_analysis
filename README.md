# ortholog_analysis
The ortholog_analysis project is designed to retrieve and analyze ortholog data from Ensembl and WormBase APIs.

## Overview
The project appears to be focused on ortholog analysis, utilizing APIs from Ensembl and WormBase to retrieve gene and homology data. It retrieves homology data for a list of gene IDs and then converts the data into a DataFrame.

## Installation
To install the project, follow these steps:
```bash
# Clone the repository
git clone https://github.com/GuerreroVazquez/ortholog_analysis.git
# Navigate to the project directory
cd ortholog_analysis
# Install required packages
pip install -r requirements.txt
```
Please note that you need to have Python and pip installed on your system.

## Usage
To run the project, follow these steps:
```bash
# Navigate to the project directory
cd ortholog_analysis
# Run the project
python main.py
```
Please replace `main.py` with the actual script name.
